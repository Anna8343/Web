Вступ до CSS

CSS — це мова стилів для оформлення HTML-документів. CSS дозволяє змінювати кольори, шрифти, відступи та інші візуальні характеристики елементів на веб-сторінці.

Способи додавання CSS:

  • Вбудований (атрибут style)
  • Внутрішній (тег style в head)
  • Зовнішній (окремий файл .css)
