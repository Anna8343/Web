Список визначень

HTML
Мова розмітки гіпертексту, що використовується для створення веб-сторінок.
CSS
Каскадні таблиці стилів, що використовуються для опису зовнішнього вигляду документа, написаного мовою розмітки.
JavaScript
Мова програмування високого рівня, що використовується для створення інтерактивних веб-сторінок.
HTTP
Протокол передачі гіпертексту, що є основним протоколом для передачі даних у Всесвітній павутині.
